## Unit header

**Unit purpose (as-is).** Root-level components under `src/components/` that render site-level compliance and reporting surfaces: an on-screen KPI/deliverables dashboard (ComplianceDashboard), three PDF-producing report panels (ComprehensiveInspectionReport, SiteSummaryReport, FortressMarkingChecklist), a reusable site health-score pill with its only test (SiteHealthBadge + test), an admin dashboard widget of recent site assignments (RecentAssignmentsWidget), and an admin RLS-policy viewer/role editor (UserRLSPolicies).

**Module-level observations.**
- Six of the seven source files query Supabase directly through the L19 singleton client (`@/integrations/supabase/client`); SiteHealthBadge is the only pure-presentational component (props in, JSX out, zero I/O — src/components/SiteHealthBadge.tsx:26-67).
- The three PDF-producing components share one preview pattern: generate blob → `URL.createObjectURL` → `DocumentPreviewDialog` (C15) → `savePDFToDocuments` (L14) → `URL.revokeObjectURL` on close (ComprehensiveInspectionReport.tsx:190/211/228; SiteSummaryReport.tsx:627/645/668; FortressMarkingChecklist.tsx:261/281/416).
- `savePDFToDocuments` catches internally and returns `{success, error}` (src/lib/pdfDocumentSaver.ts:29,39,41,122); the two callers whose save handlers have `try/finally` with no `catch` (ComprehensiveInspectionReport.tsx:209-224; FortressMarkingChecklist.tsx:279-294) therefore do not surface a throw from that helper.
- SiteHealthBadge.test.tsx is the unit's only test file; no test anywhere in `src/` references the other six components (grep over `src/**/*.test.{ts,tsx}` for each component name: zero hits).
- ComplianceDashboard and SiteSummaryReport both call `computeSiteHealth` from L17 (ComplianceDashboard.tsx:131; SiteSummaryReport.tsx:276), and both carry code comments stating this keeps screen and PDF numbers aligned (ComplianceDashboard.tsx:129; SiteSummaryReport.tsx:271-275).
- User feedback is sonner toasts in all data-mutating files; ComplianceDashboard instead renders inline error text (ComplianceDashboard.tsx:262-265); SiteHealthBadge has no failure states.

**External contract.** The rest of the app gets: `<ComplianceDashboard>` and `<FortressMarkingChecklist>` mounted by V01 SiteDetail (src/views/SiteDetail.tsx:8,26); `<ComprehensiveInspectionReport>` mounted by V01 InspectionDetail (src/views/InspectionDetail.tsx:17) and V07 InspectionsTab (src/views/subsection-detail/InspectionsTab.tsx:12); `<SiteSummaryReport>` mounted by C08 SiteReports (src/components/site/SiteReports.tsx:7); `<SiteHealthBadge>` used by C03/V01/V03 (five call sites, listed per-file below); `<RecentAssignmentsWidget>` mounted by V01 Dashboard (src/views/Dashboard.tsx:9); `<UserRLSPolicies>` mounted by V02 Users (src/views/Users.tsx:50).
